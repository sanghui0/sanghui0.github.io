# 쇼츠쿡 개인정보처리방침

시행일: 2026.10.23

※ 인기 레시피 탐색·만드는 법에서 재료 자동 채움·Meta 설치 측정에 관한 내용은 해당 기능이 포함된 앱 버전부터 적용됩니다.

쇼츠쿡(이하 "앱")은 이용자의 개인정보를 소중히 다루며, 아래와 같이 개인정보 처리방침을 안내합니다.

## 1. 수집하는 정보

앱은 회원가입이 없으며, 이름·이메일·전화번호·위치정보·광고 식별자(IDFA)를 수집하지 않습니다. 앱이 처리하는 정보는 다음과 같습니다.

- **유튜브 영상 링크**: 이용자가 공유하거나 붙여넣은 유튜브 영상 링크
- **이용자가 저장한 레시피와 사진**: 레시피 내용, 이용자가 촬영하거나 사진 보관함에서 고른 사진
- **앱 이용 통계**: 앱 실행, 레시피 불러오기 시도·성공·실패, 저장한 레시피 열람 같은 이용 기록과 앱 설치 단위의 식별자, 기기 모델·OS 버전 등 기본 기기 정보
- **공개 유튜브 레시피 조회 정보**: 인기 레시피 탐색에 사용하는 공개 영상 ID와 조회 시각. 개인이 작성·수정한 레시피 내용과 사진, 조회자의 이름·계정은 공용 목록에 포함하지 않습니다.
- **레시피·재료 추출을 위한 입력**: 이용자가 불러오기를 선택한 클립보드의 레시피 글, 다음 단계를 눌러 재료 추출에 사용하는 조리 설명
- **광고 설치 측정 정보**: Meta SDK의 설치·앱 활성화 정보와 앱 설치 단위의 익명 식별자, 앱·기기·OS 정보. 네트워크 통신 과정에서 IP 주소 등이 처리될 수 있습니다. IDFA를 읽거나 앱 추적 허용(ATT)을 요청하지 않습니다.

## 2. 정보 처리 목적 및 저장 위치

- **유튜브 영상 링크**는 레시피를 추출하기 위해 자체 운영하는 서버(Cloudflare Workers)로 전송됩니다. 서버는 YouTube Data API로 해당 영상의 공개된 설명란과 고정 댓글을 조회하고, 그 텍스트를 OpenAI API로 보내 재료와 조리 순서로 정리합니다. 같은 영상을 다시 요청할 때 빠르게 응답하기 위해 **영상별 추출 결과만** 서버에 일정 기간 보관하며, 이 결과에는 누가 요청했는지에 관한 정보가 포함되지 않습니다.
- **저장한 레시피와 사진**은 기본적으로 **이용자의 기기 내부에 저장**됩니다. 다만 재료 단계로 넘어가면 작성한 만드는 법이 자체 서버를 거쳐 OpenAI API로 전송되어 재료·분량을 추출합니다. 클립보드에서 레시피 글을 불러오는 경우에도 선택한 글이 같은 경로로 전송되어 레시피로 정리됩니다. 이 개인 입력과 사진은 공용 인기 레시피에 게시하지 않습니다.
- **인기 레시피**에는 서버가 공개 유튜브 설명·댓글에서 추출한 원본 레시피만 표시합니다. 공개 영상 ID의 최근 조회 정보를 공용 목록 정렬에 사용하고 부족한 항목은 기존 공개 추출 캐시로 채우며, 개인 수정본이나 직접 작성한 레시피는 공유하지 않습니다. 기존 공개 영상 정보의 캐시 보관 기한은 최대 30일이며, 최근 조회 관련 기록은 기능 운영에 필요한 제한된 기간만 보관합니다.
- **클립보드**는 홈에서 텍스트 존재 여부만 확인한 뒤, 이용자가 불러오기를 선택한 경우에만 내용을 읽습니다. 시스템이 붙여넣기 권한을 요청하면 이용자가 허용 여부를 결정합니다. 읽은 내용은 선택한 레시피 불러오기·추출에만 사용합니다.
- **카메라와 사진 보관함**은 이용자가 레시피에 사진을 넣을 때에만 사용하며, 이용자가 고른 사진만 기기 안에 저장합니다.
- **앱 이용 통계**는 앱 개선을 위해 Google LLC의 Firebase 애널리틱스로 수집됩니다. 개인을 식별하는 정보와 결합하지 않으며, 광고나 추적 목적으로 사용하지 않습니다. 자세한 내용은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 참고하시기 바랍니다.
- **Meta 설치 측정**은 광고에서 앱 설치·실행으로 이어지는 성과를 측정하기 위해 사용합니다. IDFA 수집·자동 구매 이벤트·코드리스 추적은 사용하지 않습니다. 자세한 내용은 [Meta 개인정보처리방침](https://www.facebook.com/privacy/policy/)을 참고하시기 바랍니다.

## 3. 처리 위탁 및 제3자 제공

앱은 이용자의 정보를 판매하지 않습니다. 서비스 제공을 위해 아래 업체의 서비스를 이용합니다.

| 업체 | 처리 내용 |
|---|---|
| Cloudflare, Inc. | 레시피 추출 서버 운영 |
| Google LLC (YouTube Data API) | 영상의 공개된 설명란·고정 댓글 조회 |
| OpenAI, L.L.C. | 설명란·댓글 및 이용자가 불러온 레시피 글 정리, 이용자가 작성한 만드는 법에서 재료 추출 |
| Google LLC (Firebase 애널리틱스) | 앱 이용 통계 |
| Meta Platforms | 광고 설치·앱 활성화 성과 측정 |

## 4. 이용자의 권리

- 저장한 레시피는 앱에서 언제든지 수정하거나 삭제할 수 있습니다.
- 앱을 삭제하면 기기에 저장된 레시피와 사진도 함께 삭제됩니다.
- 카메라·사진 접근 권한은 iPhone 설정 > 쇼츠쿡에서 언제든지 끌 수 있습니다.
